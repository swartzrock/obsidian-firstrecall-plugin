Grounding Context

This is not simply an AI flashcard generator. It turns existing Markdown notes into living, in-place recall practice: a whole-note brief plus heading-aware study material, while leaving the source untouched.

The current manifest promises “in-note active-recall sessions” and says Markdown is never modified. The README adds the essential interaction: learners reveal answers one section at a time in Editing or Reading view. That experience—not the internal term cue—is the durable product.

Why retire CueCraft? Exact-name web collisions already include an AI yoga product, an AI production cue manager, and a nursing education platform. The overlap is close enough to create search and category confusion. This is a naming scan, not trademark clearance.

Idea 1 · Recommended

First Recall

Confidence · 93%

Description: Frames the workflow as active-recall first: retrieve from memory, then uncover the source context.

First Recall — test memory, then open the note.
Basis
direct: The plugin’s core loop is hidden note content, learner response, then reveal. external: “First recall” communicates the retrieval-first learning order in plain language.
Rationale
It is distinctive enough for branding, directly tied to the user outcome, and still generic enough to support future extensions beyond section prompts.
Downsides
Any phrase with “Recall” risks competition in search; a formal name-search and package check is still required.
Complexity
Low
Idea 2

Second Brain

Confidence · 82%

Description: Leverages the familiar “second brain” metaphor while explicitly indicating this plugin is for retrieval practice.

Second Brain — your note vault, now quiz-ready.
Basis
direct: It acts on note-backed knowledge, converting source material into retrieval tasks.
Rationale
Strong immediate meaning in personal knowledge workflows and easy to remember in commands.
Downsides
Widely used phrase in the knowledge management space; weaker direct association with the exact study behavior.
Complexity
Low
Idea 3

Note Reveal

Confidence · 76%

Description: Names the single interaction the learner sees in Study Mode: reveal your note after trying first.

Note Reveal — pull the section, then open it.
Basis
direct: Each study cycle hides note sections and asks the learner to think before exposing them.
Rationale
Very clear, short, and low-friction to understand for first-time users.
Downsides
Less memorable than more branded alternatives and can read like a literal feature than a product name.
Complexity
Low
Idea 4

Memory Map

Confidence · 73%

Description: Highlights semantic structure: notes as connected memory locations, traversed by recall prompts.

Memory Map — move through your knowledge by section.
Basis
external: Learners often retain material better when it is organized as a map of connected concepts.
Rationale
Signals structure-oriented study, especially useful as users scale to dozens of notes.
Downsides
May be interpreted as a broader graph tool and not clearly tied to reveal-style practice.
Complexity
Low
Idea 5

Section Pulse

Confidence · 69%

Description: Focuses on section-by-section retrieval rhythm for each note, matching the plugin’s current interaction shape.

Section Pulse — active learning, chunk by chunk.
Basis
direct: The plugin already builds content and flow around section boundaries in Markdown.
Rationale
Fresh-sounding and descriptive, while preserving the “in note, in place” implementation style.
Downsides
Requires users to infer what the pulse means; not as instantly obvious as a plain verb phrase.
Complexity
Low
