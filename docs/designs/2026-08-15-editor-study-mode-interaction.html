Coding Interview Overview

Note brief

A pattern map for coding interviews: identify the data shape, then choose the stored state that turns repeated work into a lookup, a single scan, or a smaller search space.

Prefix Sum

  1. Build an array of cumulative totals from left to right.
  2. Subtract two stored totals to answer a range query.
  3. The preprocessing costs O(n), but each query costs O(1).

Two Pointers

Use two indices when each comparison tells you which side can be discarded. On sorted input, move the left pointer to increase a value or the right pointer to decrease it.

Monotonic Stack

The stack holds only candidates whose answer has not appeared yet. A new value resolves smaller candidates once, so every index is pushed and popped at most once.
