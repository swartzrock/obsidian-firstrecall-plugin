Recommendation

Ship Option A first, keep Option C as the north star.

Expanded rows preserve CueCraft's current settings architecture while making every visual choice inspectable. The live preview companion is the richer follow-up once the thumbnail component proves itself.

1
Option A: Expanded rows

Lowest implementation risk, clearest migration from dropdowns, strong enough to fix handwritten discoverability.

2
Option C: Picker plus live preview

Best long-term user confidence because combinations become visible, but it needs more layout and state work.

3
Option B or D

Good alternates depending on whether you want a gallery destination or a compact Obsidian-like preference pane.

Implementation notes

Use one reusable thumbnail-button renderer for each option list. Keep the option arrays as the single source of truth and attach a small preview kind to each item.

  • Replace dropdowns in Appearance with button groups using aria-pressed and visible focus states.
  • Convert toggles into paired thumbnail buttons: Border on/off and Comfort/Compact supports.
  • Keep accent buttons as thumbnails that show cue rail and support tint, not just colored circles.
  • Make Handwritten a normal style thumbnail with dashed border, rotated cue card, and handwriting-like strokes.
  • Use existing Obsidian variables in production CSS, while keeping the abstract renderings small and stable.
