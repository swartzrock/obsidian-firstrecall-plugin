FirstRecall vocabulary review

The interface should explain itself.

A proposal for language that starts with what learners recognize—not how FirstRecall is implemented.

Before · brand vocabulary first

Users meet the nouns before the meaning.

The central object

Name the thing people can see.

“Cue” is a valid learning-science term. It is not an obvious name for a card containing three different kinds of content.

Card anatomy

Name each part by its purpose.

The strongest terms tell learners not only what content is present, but how to use it.

Opening copy

Lead with value, not vendors.

The provider card immediately below can explain model setup. The introduction should establish what FirstRecall makes and what it protects.

Recommendation

Ship one vocabulary system.

Treat this as an interface contract change across every place a learner encounters FirstRecall—not a settings-page copy patch.
