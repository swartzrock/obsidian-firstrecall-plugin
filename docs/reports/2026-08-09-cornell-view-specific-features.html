CueCraft capability report

Cornell View feature guide

A practical inventory of the experiences that depend on CueCraft's dedicated Cornell pane, how to use them correctly, and the value each one provides.

6 user-facing capability groups specific to the Cornell pane Verified against the current implementation on August 9, 2026.

Start a Cornell review

The fastest route is Review This Note (Study Mode). It verifies that the active note has usable cues, opens the dedicated pane, and starts with source sections hidden.

  1. Prepare the noteOpen a Markdown note and run CueCraft: Generate Cues for This Note if it does not already have cues.
  2. Open the reviewUse the Command Palette and choose CueCraft: Review This Note (Study Mode). A note's context menu offers the same action when usable cues exist.
  3. Recall, then revealRead the question, answer from memory, then click its cue card to reveal only the matching source section. Click again to hide it.
Browse without hiding answers: use the two-column ribbon icon or CueCraft: Open Active Note in Cornell View. Then turn on Study mode from the pane toolbar when ready.

Cornell-specific capabilities

01

Paired cue-and-source layout

Cornell-only surface

Every generated question sits in a stable left rail beside the section of the original note that answers it. The note title and final Note Brief or takeaway complete the review sheet.

Use it properly

  1. Open the active note in Cornell View.
  2. Scan down the cue rail while using the right column for context.
  3. Use Display to choose a width that keeps questions readable without squeezing the source.

User benefit

Reduces the back-and-forth between a detached flashcard and its source. Users can verify an answer in context while the Markdown remains untouched.

02

Per-section Study Mode reveal

Core review loop

The Cornell pane can hide every source section while leaving its question visible, then reveal answers independently as the learner progresses.

Use it properly

  1. Open Review This Note (Study Mode), or enable the toolbar toggle.
  2. Answer the visible question before interacting with the card.
  3. Click the cue to reveal its matching section; click again to hide it.
  4. Turn Study mode off to restore every section.

User benefit

Creates a real retrieval-practice sequence: prompt, effortful recall, then immediate verification. Independent reveals limit accidental exposure to later answers.

Current gaps: the data model supports a reveal-all/reset state and product stories describe Hide all answers, but the current Cornell toolbar has no separate visible button for it. Toggling Study mode off and on is the available reset. The settings UI also offers Blur and Collapse hide styles, but Cornell View currently always uses blur.
03

Hook rail focus navigation

Alternate mode

Hook rail replaces full cue cards with compact, memorable titles. Selecting one marks it current, scrolls the matching source section to the center, and moves keyboard focus there.

Use it properly

  1. Exit Study mode.
  2. Open Display and set Mode to Hook rail.
  3. Click a hook to jump to its section.
  4. Switch Mode back to Cornell for full questions or Study mode.

User benefit

Provides fast orientation in long notes. Short labels act as landmarks, while scroll-and-focus removes manual searching for the related section.

Mode rule: Hook rail and Study mode are mutually exclusive. Choosing Hook rail turns Study mode off; Study mode always uses the full Cornell cue presentation.
04

Targeted cue repair with tone choices

Actionable in place

A low-confidence cue gets a warning, and any cue can be regenerated for only its section with a different tone: More conceptual, Exam prep, Simpler, or Vocabulary.

Use it properly

  1. Keep Study mode off.
  2. Hover a cue, or find the persistent regenerate icon on a low-confidence cue.
  3. Choose a tone that addresses the problem.
  4. Review the replacement beside the unchanged source section.

User benefit

Repairs one weak prompt without paying the cost or accepting the churn of regenerating the whole note. Tone choices make the correction purposeful rather than random.

05

Stale and failed-section recovery

Batch and local actions

The pane exposes Refresh stale for changed sections, a failure banner with Retry failed, and an in-card regenerate action when a single cue is unavailable.

Use it properly

  • After editing the note, exit Study mode and choose Refresh stale.
  • In Cornell mode, use the failure banner to retry all failed sections.
  • Use a failed card's Regenerate or Retry action when only one section needs attention.

User benefit

Keeps the review set synchronized with the note and makes partial generation failures recoverable without discarding successful cues.

06

Pane-specific display controls

Presentation

Cornell View has live controls for mode, paper style, cue-column width, and cue font size, plus settings for accent, divider, support density, and narrow-screen stacking.

Use it properly

  • Use Display for quick changes: Cornell or Hook rail, Cornell Classic / Exam Prep / Legal Pad / Minimal / Handwritten, Narrow / Medium / Wide, and Small / Medium / Large.
  • Use Settings → CueCraft → Cornell View for cue accent, border, compact supports, and mobile folding.
  • Enable mobile folding when a narrow pane should stack each cue above its source instead of maintaining two squeezed columns.

User benefit

Lets users tune information density and legibility for different screens and note shapes. These are comfort and scanning controls; they do not alter generated cue content.

Recommended workflows

Active-recall pass

Best for checking retention after reading.

  1. Choose Review This Note.
  2. Answer one question aloud or in your head.
  3. Reveal and compare.
  4. Hide it and continue.

Repair pass

Best after generation or substantial edits.

  1. Refresh stale sections.
  2. Retry failures.
  3. Inspect low-confidence cues.
  4. Regenerate weak cues with a deliberate tone.

Orientation pass

Best for long notes you have not visited recently.

  1. Switch to Hook rail.
  2. Scan compact section hooks.
  3. Select unfamiliar hooks to jump into context.
  4. Return to Cornell mode for full review.

Features that should not block removal

These appear in Cornell View, but their underlying user value is already available in Editing or Reading mode. They are shared CueCraft capabilities, not reasons by themselves to keep a dedicated pane.

  • Generated questions and termsCached cues can already render alongside the original note in Editing and Reading modes.
  • Note BriefThe overview card is rendered across note surfaces, not only in Cornell View.
  • Section LensThe extra framing text belongs to cue content and is available outside the dedicated pane.
  • Non-destructive storageGenerated data lives in plugin storage regardless of which view displays it; the Markdown remains unchanged.
Removal implication: preserving Cornell View's value means migrating the interaction capabilities, especially per-section reveal, targeted regeneration, focus navigation, and in-context recovery. The shared generated content already has other homes.
