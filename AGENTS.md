## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues; external PRs are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five-label triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout. See `docs/agents/domain.md`.

Do not launch `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` directly.
For browser work, use the in-app Browser plugin. To open a URL or file visibly for me,
use `open -a "Google Chrome" <url-or-path>` or Safari.
